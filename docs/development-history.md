# Dayly · 肌肉与动作实验室

React + TypeScript + Three.js 健身交互应用。

```bash
npm install
npm run dev
npm test
npm run build
```

本地地址：http://127.0.0.1:5173/ 。修改后若仍看到旧版，强制刷新浏览器。

## V4 当前实现

- 使用 Z-Anatomy 的实际肌肉分割：腹直肌、背阔肌不再使用补充条带/椭球；保留肌腹与肌腱分区，增加方向性表面纹理显示。
- 49 个骨骼关节，全部人体网格共享 Skeleton，通过 skinIndex/skinWeight 蒙皮；肩、肘、髋、膝、腕的交界连续分配权重。
- 手腕、四指指节及拇指独立；哑铃固定在掌心握持点，手指弯曲环握。哑铃采用独立金属手柄与六角配重。
- 俯卧撑固定双手与脚部，通过两段骨骼逆运动学求解肘部；从接近伸肘下降至胸部接近地面。添加手掌接触、躯干直线与胸部下放提示。
- 深蹲、划船、弓步蹲、卷腹、臀桥等的末端位置约束；修复切换动作后同一进度值未应用到模型的问题。
- 16 类肌群，主练红色、辅助金色；播放和暂停持续高亮。演示中点击查看名称，探索中点击选择目标。
- 882 条动作记录（876 条来源记录 + 14 个自编示例 - 8 条等价合并）；40 个 3D 示意、42 份常用动作中文详解，其余保留来源步骤或明确提示步骤缺失。支持中英文名称检索、器械/肌群/内容筛选及每页 30 条分页。
- 详细指导包括准备姿势、完整步骤、呼吸、错误与纠正、难度调整和组次。训练推荐仅从有中文详解且可播放的条目中生成，导出 JSON 包含完整指导和 3D 支持标记。
- 头颈和脚踝沿原始表面延伸过渡区、收拢边缘、平滑边界并渐变贴合邻近解剖表面，与肌肉使用一致的中性色及粗糙度。脸、手、足仍为表皮，未冒充这些部位的完整解剖肌肉。
- GLB 导出保留骨骼、逆绑定矩阵、蒙皮权重与当前姿态。未烘焙动画轨道；网页中的程序动画独立运行。
- 按姿态与屏幕宽度调整镜头，手机可完整显示横向俯卧撑。

## 核心文件

- `src/bodyRig.ts`：共用骨架、指节与哑铃握持点。

- `src/movement.ts`：所有动作姿态、逆运动学和阶段提示。

- `src/catalog.ts`：来源记录合并、分类映射、检索与内容支持。
- `src/ExerciseGuide.tsx` / `src/data/guides.json`：42 份中文指导与来源步骤。
- `scripts/build_anatomy_v4.py`：Blender 解剖网格加工流程。
- `research/movement-v4.md`：动作来源、实现及验收边界。

- `artifacts/dayly-v4-skinned-pushup.glb`：实际通过网页导出的带骨架俯卧撑姿态。

## 资产与验证边界

肌肉与骨骼来自 Z-Anatomy / BodyParts3D；头、手、足皮肤来自 BodyParts3D。保留上游要求的 CC BY-SA 4.0、CC BY-SA 2.1 Japan 署名及许可说明。分发衍生模型时附带 NOTICE。源网格中不使用内耳、肾脏等其他第三方器官资产。

表面纹理表现肌纤维方向，不是实测纤维结构；红/金色表达动作中的肌群作用，不是肌电测量。当前采用线性蒙皮和人工编排动作，无运动捕捉、肌肉力学求解或全身软组织碰撞。自动检查与关键帧目视检查不等同于专业教练逐动作审核，尚无该项专业验收。

文本识别为本地规则，不能理解任意自由描述。推荐从已收录动作组合，未按伤病或个人训练史生成处方。

### 目标导向训练计划

- “训练计划”入口支持自选肌群、腹肌强化、减脂、提升心肺和全身力量。原肌群推荐保留；腹肌目标仅推荐直接训练核心的动作，全身计划按蹲、推、拉、髋伸选择不同动作模式。
- `src/trainingPlan.ts` 集中生成目标对应的组次、休息、每周频率、热身、放松与进阶建议。器械和难度严格过滤力量动作；缺少动作模式时披露缺口，不用重复动作补数量。
- 减脂为力量与快走组合；心肺目标为独立快走安排，入门时长更短。快走是额外的文字训练环节，明确标记暂无 3D，不改变 40 个可播放动作的计数。腹肌页面说明无法局部减脂。
- 切换目标、肌群或筛选会清除旧计划；进入动作指导后显示本次计划剂量，返回计划仍保留结果。JSON 导出包含目标、训练安排、有氧步骤及动画支持情况。
- 验证：30 项测试通过，构建通过；浏览器验证五种目标、空结果、入门有氧、下载 JSON、动作演示入口与返回保留；390px 手机页面无横向溢出。截图见 `artifacts/goal-plan-mobile.png`，实际导出见 `artifacts/cardio-goal-plan.json`。

### 电脑训练工作区与跟练模式

- 主导航按“训练计划 / 动作指导 / 动作库”组织；电脑端模型保持可见，计划及指导区域独立滚动。生成计划后收起设置；动作指导可连续查看前后动作、返回原计划。
- 本机保存目标、器械、难度、肌群、计划设置与最近查看的 5 个动作；刷新恢复。没有后台账户同步，不保存或推断真实运动完成量。
- 点击“按计划跟练”，选择 4 / 6 秒一次的演示速度，确认是否包含 5 分钟热身，再点击“开始跟练”。次数、保持时长、休息范围均明确采用下限。
- 顺序执行热身、动作准备、各组各次、组间休息、换动作休息、快走（如有）与 3 分钟放松。弓步动作每组分两侧执行，第二侧镜像演示；平板支撑按秒保持。快走只有计时、文字和口令，不冒充已有步行动画。
- `src/followSession.ts` 是纯时间与组次编排逻辑；`src/FollowAlong.tsx` 驱动模型的受控相位、计次与界面，同一时钟触发音频。暂停、空格快捷键、跳过、切到后台自动暂停；卡顿超过 1 秒暂停，避免静默跳过次数。
- `src/followAudio.ts` 提供本地 120 BPM 原创合成节奏（鼓点、低音、旋律）及 82 段中文口令，报数、准备提示、休息与鼓励均无需浏览器中文语音支持。音乐与口令分别开关，口令播放时降低音乐音量。
- 语音资源位于 `public/audio/coach`，由 macOS Tingting 合成；`scripts/generate-coach-audio.py` 和 `manifest.json` 保留生成方法与原文。不是专业教练真人录音。
- `artifacts/follow-along-demo.mp4`：17 秒实际模型与实时计次合成录屏，包含浏览器播放的口令及节奏混音（H.264 + AAC，1200×720）。界面截图见 `artifacts/follow-running-desktop.png`。

### 徒手默认与常用操作位置

- 新计划默认“无需器械”。旧版默认保存的“全部器械”迁移为徒手；明确选择的哑铃等器械继续保留。新选择的“使用器械 / 全部”带明确选择标记，可正常恢复。
- 未指定器械的计划生成接口也默认徒手；不会为了补齐动作而自动加入器械。上斜俯卧撑（需要支撑平台）和靠墙抬脚尖不进入无需器械组合。没有合适的可播放动作时说明缺口。
- “生成训练计划 / 开始跟练”固定在计划面板顶部，同时显示目标、器械、动作数和预计时间。动作预览的播放键前移到标题下方。
- 跟练的开始、暂停、继续、跳过放在模型下方的固定操作区，旁边显示当前次数 / 倒计时和组数；电脑侧栏继续提供大字号当前状态。
- 37 项测试与构建通过。浏览器验证首次徒手默认、主动选择哑铃、刷新恢复、固定按钮在滚动后仍可见，以及 1366×768 电脑与 390px 手机操作区。

### 一次点击启动与一分钟热身

- 计划页点击“开始跟练”即启动：在该次点击中解锁音频，模型和口令准备完成后自动计时，不再进入需要第二次点击的准备页。
- 默认热身从 5 分钟改为 1 分钟，计划文案、预计总时长及 `warmup-short` 中文口令同步调整。热身时显眼提供“已热身，直接开始”。
- 热身开关和 4 / 6 秒动作节奏前移到计划页“跟练设置”；选择已热身后，启动直接进入首个动作的准备倒计时。
- 音频加载失败时会说明并静音继续，避免再次卡在启动按钮；返回计划会清理音频，暂停 / 继续与后台暂停行为保持。
- 38 项测试通过；浏览器验证一次点击后 1:00 自动推进到 0:59，页面没有第二个“开始跟练”按钮；跳过热身、事先关闭热身、暂停冻结、继续、返回计划均通过。


### 关节旋转、握姿与肌肉连接修复（2026-09-09）

- 上臂与前臂共享肘关节弯曲平面，膝部采用一致的屈伸轴。修复独立最短弧旋转导致的外翻和过顶动作突跳；不可达 IK 目标保持骨段长度。
- 每侧前臂增加 3 个轴向旋转骨骼，把转掌分散到前臂。肱骨、尺骨不参与前臂轴向转动，桡骨随远端旋转；这是简化蒙皮，并未模拟桡尺关节的真实双轴运动。
- 推举掌心朝前，锤式弯举和活动绳索把手使用对握，侧平举顶部掌心朝下。前蹲、后蹲、卧推、硬拉分别设置握姿。柔性把手联合求解掌心偏移与腕点，保持握持连接。
- 移除肩部 y=2.95 处的绑定跳变，三角肌及肩袖按内侧起点与肱骨附着区连续分配权重；臂骨刚性绑定，肘部过渡收窄至关节附近，上臂肌腹保持随肱骨运动。肩胛骨、锁骨不再按肩部肌肉字段弯曲。
- 调整俯卧撑支撑位置、深度和肘部方向，兼顾固定接触、动作幅度、肘腕角度；架杠位置与脚底约束保留。
- `src/biomechanics.test.ts` 对 40 个动作各采样 201 帧，检查关节轴、屈伸范围、转掌方向、腕部弯曲、逐帧连续性和掌面朝向。真实 GLB 回归覆盖臂骨及肌腹刚性、肩部网格短边异常拉伸。
- `artifacts/arm-audit-before.json` / `arm-audit-after.json` 为旋转诊断；`skin-audit-before.json` / `skin-audit-after.json` 在相同修正姿势下比较旧、新蒙皮。局部边长比仅用于捕捉渲染裂片，不代表生理肌肉应变或医学验收。
